CURSIMPLE PLUGINS

登录教务，把课表导进课简

每所学校由独立插件适配。搜索你的学校，安装对应插件，登录教务系统后课表会自动导入。

在课简中安装

打开课简的「从教务系统导课」，搜索学校名并安装对应插件，插件装好会自动启用。也可以从插件仓库的 Release 下载插件 ZIP，再用「导入 ZIP」安装。

导入时在插件页面登录学校教务系统，账号只提交给学校。兼容版本以插件详情为准；学校系统改版后，插件需要更新才能继续导入。

把你的插件加入收录

网页和课简的导课页共用 plugins.json。提交仓库地址和覆盖的学校，合并后由工作流更新收录资料。

在 GitHub 编辑 查看贡献说明

准备插件包

插件仓库需公开托管在 GitHub。Release 附件需要同时上传插件 ZIP 与下载清单 manifest.json，清单里的 filename 要和 ZIP 文件名一致。

注册条目示例

{
  "repo": "your-name/your-school-plugin",
  "schools": ["示例大学", "示大", "shilidaxue", "sldx", "Example University"]
}

schools 请写全学校全称、常用简称、拼音全拼与首字母、英文名或缩写。课简按子串匹配搜索，不做拼音转换。
